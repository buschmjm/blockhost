# Roadmap

Ideas, roughly in order. Open an issue to discuss before starting a big one.

- Scheduled world backups with retention, and one-click restore.
- Pin or roll back the Bedrock server version.
- Code-signed Windows build (removes the SmartScreen warning).
- System tray icon for the desktop builds.
- Read-only "status" page to share with players.
- More mod settings: entity component groups, block properties, biome spawn rules.
- Mod update checks against source sites.
- Multiple servers from one Blockhost (different worlds on different ports).
